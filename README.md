# Government Scheme Finder

## About
Government Scheme Finder is a Python and Streamlit web application designed to help people discover Indian government schemes and explore potential eligibility based on their circumstances.

## Features
- Browse and search government schemes
- Filter schemes by eligibility criteria
- Find potential scheme matches
- View benefits, required documents and official links
- Download PDF eligibility reports
- Manage scheme records through an admin dashboard
- Import and export scheme data using CSV files

## Technology Stack
- Python
- Streamlit
- SQLite
- Pandas
- ReportLab

## Disclaimer
This is an independent informational project, not an official government service. Eligibility matches are preliminary guidance. Users should verify scheme requirements with the relevant government department.

## Project Status
The application is under development. Improving scheme coverage, data accuracy and verification is ongoing.
